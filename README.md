📚 BookLoop

A full-stack MERN application for buying, selling, and renting books.

Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer
- Cloudinary

Features
- User Authentication
- Buy Books
- Sell Books
- Rent Books
- Wishlist
- Shopping Cart
- Search & Filters
- Responsive UI
